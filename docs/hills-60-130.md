## Evidence

final boundary recaptures. Collection counterfactuals:
`bench/artifacts/round2-collections-final.json`; paired async results and memory
samples are separate adjacent artifacts. These runs use immutable snapshots;
several compare isolated counterfactual algorithms rather than historical
releases. Shared-host timings are observations, not universal rankings. Only the
ABBA result above includes a statistical interval.

Production rejection keeps small tested experiments under `bench/experiments`.
An implemented structural allocation reduction is not automatically a speedup.

## Qualification

`TMPDIR=/var/tmp npm exec --yes --package=bun@1.4.3 -- deno task verify` passed:
339 runtime/example/application tests, 6 experiment tests, 10 tooling tests, 88
transformer tests, three assertion-qualified mutation kills, package exports,
Node, Bun, browser, workerd, and repeated application observations. One existing
intentional test remains ignored. Coverage is 79.5% lines, 87.3% branches and
81.6% functions. Plain `deno test` separately passes 347 tests with that same
ignore.

Toolchain checks, deterministic budgets, and `deno task publish:dry-run` pass.
The Node gate caught a non-erasable STM parameter property; the final journal
uses ordinary fields and the portability scanner now rejects parameter
properties.

Final snapshots: `round2-types-final.json`, `round2-import-final.json`, and
`round2-type-features.json`. Runtime API timing: `round2-api-measurement.json`.
Transformer timing, application controls, profile summary and explicit lowering
rejection are retained in adjacent `round2-*` artifacts. Their fingerprints
identify measured source; final validation covers later portability/type-only
changes. No performance result implies every workload improves.
