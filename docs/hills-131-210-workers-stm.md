# Workers and STM: hills 135, 181–192

Measurements use Deno 2.9.7 / V8 15.0.245.2 on the recorded host target. The
artifacts record exact versions and SHA-256 source fingerprints; use those
values if the installed toolchain changes. The candidate snapshot contains
baseline dependencies with only `src/parallel.ts` and `src/stm.ts` replaced,
isolating this work from the concurrent core/Task changes. Benchmarks are
serialized with `flock /tmp/typeclasses-round3-bench.lock`.

`bench/artifacts/round3-workers-stm-baseline.json` and `-current.json` contain
seven samples per row. `-paired.json` alternates baseline/candidate order for
nine samples after 100 alternating warmups. Prefer the paired results where
available. Worker scheduling remains noisy: individual samples and regressions
are retained.

The first worker draft allocated an AbortController on every message; batch8
regressed and that default was removed. Cooperative controllers now exist only
when explicitly enabled on the worker. The shape path is intentionally optional:
its flat-record win does not justify making slower array snapshots the default.
The versioned overlay prototype deliberately does not accept raw Maps; the
previous cache's stale miss cannot be repaired by a counter that callers can
bypass.

Final review also checks sparse immutable arrays with an own `constructor`
property: path copying allocates ordinary arrays and preserves holes/custom keys
without invoking species. Cooperative cancellation retains admission until the
final assignment is acknowledged or terminated. Stream cleanup runs exactly once
and aggregates a work failure with an iterator-return failure; pre-aborted
streams never acquire inputs. These fixes follow the timing snapshots and are
covered by regression tests; no new throughput result is attributed to them.

Final focused verification: 54 worker/STM/runtime tests passed, with source
checks and lint clean. The repository-wide gate is recorded in the integrating
ledger.

```sh
flock /tmp/typeclasses-round3-bench.lock deno run --allow-read --allow-write=bench/artifacts bench/round3_workers_stm_paired.ts BASELINE CANDIDATE bench/artifacts/round3-workers-stm-paired.json
deno run --allow-read --allow-write=/tmp,bench/artifacts bench/round3_workers_stm_allocations.ts BASELINE CANDIDATE bench/artifacts/round3-workers-stm-allocations.json
```

The allocation probe writes counted copies inside the supplied `/tmp` snapshots;
original source files remain unchanged. It counts constructor calls, not
retained heap bytes or allocations removed later by the JIT.
