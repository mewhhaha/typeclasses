Evidence in `bench/artifacts/`:

- `round3-runtime-{baseline,candidate,paired}.json`: ordinary API timings;
  candidate also measures supported chunk logs and prepared cells.
- `round3-runtime-strict-do-experiment.json`: guarded strict-runner experiment;
  `bench/experiments/round3_strict_do.patch` preserves the runner
  implementation, rebased on the completed initializer factories.
  `git apply --check` and all 11 runtime regressions pass on the patched
  snapshot.
- `round3-runtime-attempts.json`: continuation chunks, explicit fusion and empty
  prepared tables; also records both semantic counterexamples.
- `round3-runtime-dynamic-plan{,-forwarded}.json`: dynamic Effect continuation
  measurements; rejected forwarding patch is adjacent to the strict patch.
- `round3-runtime-memory-{baseline,candidate}.json`: forced-GC observations and
  fingerprints. The rejected WeakRef variant kept newly flattened prefix arrays
  alive until the current job ended; only bounded-cache results are reported
  here.

The candidates above are frozen snapshots. Subsequent type-only prepared-table
validation and PURE initialization annotations do not change the measured
execution algorithms. Full integration qualification belongs to the root ledger.

Focused qualification: 68 existing/new runtime tests passed before the final two
regressions were added; all 11 tests in `src/runtime_round3.test.ts` pass
afterward. The existing 100k Task/Reader/State checks, cooperative scheduling,
operation replay, cleanup failures and cancellation tests pass. Owned source and
benchmark files pass lint. The prepared-table compile-negative case uses an
uncalled helper: it typechecks without executing invalid runtime code and passes
lint. Independent final review also fixed immutable path updates on sparse
arrays with an own `constructor: null` property; the regression preserves holes,
custom keys, the original snapshot and freezing without invoking array species.
Worker admission/stream cleanup follow-ups are tracked in the worker ledger.
