# Ergonomics and performance hills

All 60 hills were selected on 2026-10-17. Baseline:
`908d00c716f385594b1a303f37ca84f6f5548e1d`.

**Implemented** records delivered behavior. **Scoped** records a narrower safe
implementation with its boundary. **Rejected** records an exercised alternative
that was not adopted. These labels do not imply that every performance target
passed. Final aggregate measurements and the full verification gate are recorded
separately from focused correctness evidence.

## Migrations

- Use wrapped ADT names in public signatures and `Raw...` names at tuple
  boundaries. `.value()` still exposes the raw representation.
- Pass runtime cell keys, for example `state<"count", number>("count")`.
  Repeated keys share an address within their family; use a const symbol for a
  private cell. Writer cells also require their empty-log witness.
- Replace `lift_A`, `lift_A2`…`lift_A5` with `lift`, and `append` with `concat`.
  Examples are no longer root exports. Task, Reader/State/Writer, STM, Except,
  workers and uncommon wrappers use their existing focused subpaths.
- Keep `Do` for generator notation; the rejected `Do_once` prototype is
  experimental only. Use `traverse_sequential` for fail-fast callback admission
  and bounded async helpers when input demand must remain bounded.
- Choose explicit snapshots/views. Array dictionary mapping now visits sparse
  positions. Stream early exit now cancels unless `preventCancel` is set.
- Worker batching and transferables are explicit protocol options. Existing
  worker implementations must use the matching `serve_worker` protocol.

## Measurement and verification

Run timed commands separately, with other timing jobs idle. A source change
invalidates a comparison. Measurements use one shared host without CPU affinity
or frequency controls; small timing differences are indicative, not confidence
intervals. Construction, first execution, reuse and application execution are
separate workloads.

```sh
# Library checks required by AGENTS.md
deno task check
deno lint
deno test

# Fast iteration and full qualification
deno task dev
deno task verify

# Alternative algorithms and runtime scaling
deno bench --json bench/collection_choices.bench.ts
deno bench --json bench/runtime_hills.bench.ts
deno bench --json bench/worker_hills.bench.ts

# Type-lambda experiment; identical compile assertions, serial A B B A A B
deno run --allow-env --allow-read --allow-write=bench/experiments/hkt/results.json bench/experiments/hkt/measure.ts bench/experiments/hkt/results.json

# Source/editor and import budgets
deno task types:bench
deno run --allow-env --allow-read --allow-run tools/import_budget.ts

# Capture exact source state around an arbitrary measurement
deno run -A tools/capture_measurement.ts /tmp/typeclasses-measurement.json . deno task types:bench
```

Collection correctness is recorded by `src/collection_hills.test.ts` together
with the existing collection/iterable suites: 28 focused tests. Final
alternative collection timings are in
`bench/artifacts/collections-current.json`; they are counterfactual algorithms,
not an end-to-end historical library ranking. The HKT experiment stores six
samples, compiler 5.9.3 and source/workload hashes in
`bench/experiments/hkt/results.json`. Its reduced feature surface is part of the
result, not an omitted qualification.

Runtime and worker samples are in `bench/artifacts/runtime-hills-final.json` and
`bench/artifacts/workers-final.json`. Exact transform/application source
fingerprints, commands and raw observations are in
`bench/artifacts/transform-metadata.json`, the accompanying JSON/log files and
[`transform-results.md`](../bench/artifacts/transform-results.md). The transform
comparison is one isolated paired run, not a confidence interval; named iterable
compilation and parallel application execution regressed. Preserved fixtures and
unavailable prerequisites must not be counted as passing optimized coverage.

Unmet or unqualified targets remain explicit: the rejected Do_once half-runtime
experiment, conditional member narrowing and per-yield capability diagnostics
were not delivered; general eager Writer is still quadratic; full-feature HKT
replacement and a streaming-bind default were not adopted; generic-loop fusion
and universal application speedups were not achieved. Final runtime,
editor/import budgets and verification timing require their own paired artifacts
rather than extrapolation from these experiments.

## Final qualification

`npm exec --yes --package=bun@1.4.3 -- deno task verify` passes all stages: 298
tests, one existing intentional skip, 75 transformer checks, mutation checks,
entrypoint checks, Node/Bun/browser/workerd, examples, tutorial and case
studies. Line coverage is 78.2%. The supported synchronous transformed-loop
stress test now runs 1,000,000 iterations. The publish dry-run passes.

The first verification attempt stopped because Bun was absent from PATH. The
final run uses a temporary npm-provided Bun, without a project dependency.
`verify-final.json` and `publish-dry-run.json` contain complete output and
source fingerprints. Deno is 2.9.7; its checker is TypeScript 6.0.3. The
editor/HKT profilers deliberately use the repository's pinned TypeScript 5.9.3.

For future comparisons, keep the root-consumer workload and compiler fixed;
review more than 5% type-instantiation growth against the 306,472 final count.
Treat completion latency as observational on this host, not a wall-time CI gate.
The completion surface target remains open: unavailable methods still appear.
