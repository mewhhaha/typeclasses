# Performance hills 131–210

All 80 selected hypotheses have an implementation or executable experiment and
an explicit decision. Rejected prototypes remain under `bench/experiments`; they
are not installed as defaults. API additions are described in
[README.md](../README.md#benchmarks).

Baseline: `2068408`, version 0.16.0. Measurements use Deno 2.9.7/V8 15, npm
TypeScript 5.9.3 (Deno's embedded checker is 6.0.3), Node 24.12.0, and a shared
Ryzen 3800X host. No dependency or version bump accompanies this batch. Timing
runs serialize using `/tmp/typeclasses-round3-bench.lock`. Artifacts retain raw
observations and SHA-256 workload/source fingerprints. A speedup applies to its
fixture and stated construction/reuse boundaries.

Detailed evidence: [runtime](hills-131-210-runtime.md),
[collections and QuickCheck](hills-131-210-collections.md),
[workers and STM](hills-131-210-workers-stm.md),
[transformer prototypes](hills-131-210-transform.md). The core/tooling evidence
and budget review follow the index.

## Core and tooling

The paired core artifact is
[`round3-core-final.json`](../bench/artifacts/round3-core-final.json): eight
ABBA blocks, independent whole-block bootstrap intervals and immutable
`/tmp/typeclasses-round3-core-final-2` sources. These intervals characterize
this run; they do not remove shared-host, JIT or workload selection effects.

- **138–139:** focused typeclass imports, shared internal symbol dispatch and
  complete PURE dictionary initialization units allow whole dictionaries to drop
  when unused. Bundled qualification checks every retained dictionary method,
  configured views and dynamic instance replacement. Final minified neutral ESM:
  Maybe Just **14,396B**; root Just **14,542B**; full namespace **53,817B**. The
  15KB granular target and 10% root-gap target are met.
- **140:** the standard consumer fixture checks without errors but uses
  **250,695 instantiations**, versus 243,852 baseline, so the 180k target is
  missed. One observation: 1.633s check, 5.67ms completion p95. No timing
  improvement is claimed from one compiler run.
- **141,144:** tagged metadata access and arity-specialized dictionary guards
  were implemented and benchmarked, then removed. Initial map speedup **.876×
  [95% .836,.915]**; wrapper **.753×**. The mixed prototype patch
  `round3_core_rejected.patch` preserves neighboring accepted changes as context
  and is not advertised as a standalone clean patch. Final map/check controls
  have no reliable overall difference. The source omits both prototypes.
- **142:** manual single-yield iterators retain next/return/throw/dispose,
  delegation and inherited iterator helpers. Private slots preserve progress
  after Object.freeze, with next/return/throw regressions. Delegation 1000:
  **20.87→11.38µs**, paired **1.84× [1.829,1.850]**.
- **143:** reuse the existing `Functor.instance_for(value).map` with
  `.call(value, callback)` for one known dictionary. Same-current-runtime
  generic/captured dispatch: **9.33→3.29µs/1000**, paired **2.74×
  [2.638,2.863]**. This captures the implementation at preparation time;
  reacquire it after dictionary mutation. No additional dispatch API.
- **145:** weak-able kinds use WeakMap identities; registered symbols use their
  stable registry key, and primitives use stable value descriptions without a
  retained primitive map. A fresh-process 20k mismatch probe retains
  **1,526,360→653,624B** after explicit GC. This is retained-heap evidence, not
  allocation traffic, and includes harness/runtime noise. Live weak keys and
  registered symbols retain stable diagnostics.
- **146:** the frozen registration snapshot prototype bypassed callable
  ownership and partial-install atomicity. Two executable counterexamples reject
  it. Final registration 100 **117.58→119.06µs** is a small regression; no
  registration speedup is claimed.
- **197–199:** compiler-host overlays qualify simpler dictionary/member and
  collect types without changing production. On the same 105,451-instantiation
  fixture: Pick 108,048; dropping item slots 114,748 with five this-context
  errors; nondistributive capability tests 106,570; mapped collect 105,514. All
  were rejected.
- **200:** an emitted declaration overlay checks the same consumer at 29,576
  instantiations, 72% fewer. This is an experiment: producing and qualifying a
  second declaration distribution would add a build contract to this
  source-first JSR package. Ordered same-process timing samples have compiler
  warmup bias and do not establish cold latency. Production remains source.
- **201–203:** one lexical analysis is shared with iterable fusion; identifier
  resolution and imported dictionary resolution are cached. Repeated deep
  resolution is **2.71× [2.678,2.751]**. Whole 100-yield cold transform
  **2.779→2.748ms**, paired 1.005× with interval crossing 1: no overall gain.
- **205:** `source_map:false` skips source-map construction explicitly; maps
  remain the default and the cache keys include the flag. Same-runtime
  **2.812→2.410ms**, paired **1.18× [1.139,1.232]**.
- **208:** cache accounting sums retained strings/container estimates instead of
  serializing the entire transform result. This is a retention estimate, not a
  measured heap size. Full cache miss **2.684→2.589ms**, paired **1.04×
  [1.021,1.068]**; cache version includes TypeScript version.
- **209:** watch updates replace only changed import edges, with conservative
  dynamic-import/config/directory fallbacks and deletion handling. The 1000-file
  graph setup/selection fixture is **1.580→.046ms**, paired **32.6×
  [30.32,34.49]**. This excludes child checker/test execution.
- **210:** Node inspector sampling includes objects collected by minor/major GC;
  reports also contain CPU, GC pauses and latency p50/p99/max. Relative budget
  comparisons require matching workload/runtime/sample settings and reject
  invalid metrics. On 2000 runs of 256 Maybe maps, sampled allocation is
  **18,074→18,321B/run**, p99 **.204→.194ms**, summed GC pauses **5.70→8.54ms**.
  The GC metric fails an illustrative 20% budget. These single-process
  observations include harness/JIT activity; no allocation or GC win is claimed
  and noisy timing budgets are not a default correctness gate.

Import/type evidence: `round3-{import,types}-final.json`. Type overlays:
`round3-type-variants.json` and its matching
`round3-type-variants-capture.json`. Retention/profile captures:
`round3-{diagnostic,allocation}-{baseline,candidate}.json`. Capture wrappers
record all source hashes before/after and reject mutations. Snapshot copies add
measurement drivers only; baseline production sources remain those of 2068408.
Per-area timing snapshots precede the final cleanup and metadata fixes

Retention/allocation probes do not iterate wrapped values. The illustrative
relative-budget failure is retained in `round3-allocation-budget.json`.

## Reviewed budget changes

The old full-namespace 5% ceiling was 52,763.55B. **53,817B exceeds it**:
**+7.10%** versus 0.16.0. This is accepted API and shared-runtime growth;
granular imports became smaller. Compiler instantiations also grow **2.81%** and
miss the ambitious 140 target. `bench/budgets.json` explicitly records this
review, ratchets the new observed values and keeps 5% tolerance. Passing that
revised guard does not mean these two metrics improved.

## Qualification and reproduction

Final `deno task verify` passes with the new transformer, core-tool and
experiment checks wired in: 389 source/example/case-study tests, 10 experiment
tests, 16 tool tests and 97 transformer checks pass; one existing test is
ignored. Coverage is 80.0% lines, 87.8% branches and 82.6% functions, above the
required 70% line threshold. All three mutation probes are killed. Benchmark
equivalence preflights, every package entrypoint, the isolated publish-selected
consumer, Node/Bun/browser/workerd smoke tests and examples/case studies pass.
The package consumer checks a staged source directory, not an installed registry
artifact.

Plain `deno test` also passes: 401 tests, one ignored. Pinned toolchain checks,
the reviewed budget checks, publish dry-run and `git diff --check` pass. Version
remains 0.16.0; this batch does not publish a release.
`bench/artifacts/round3-verification.json` records source and log fingerprints.
